## What scripts do
0-alias: Create alias.\
1-hello_you: Print "Hello" and current user.\
2-path: Add a dir to the end of $PATH.\
3-paths: Count dir in path.\
4-global_variables: List environment var.\
5-local_variables: List all env var, local var, functions.\
6-create_local_variable: Create a local var.\
7-create_global_variable: Create a global var.\
8-true_knowledge: Add 128 with a value of an env var.\
9-divide_and_rule: Division math of 2 vars.\
10-love_exponent_breath: Power math of 2 vars.\
11-binary_to_decimal: Convert bin to dec.\
12-combinations: Print possible combi of 2 letters except oo.\
13-print_float: Print number w/ 2 dec places.\
14-decimal_to_hexadecimal: Convert dec to hexadec.
