## What sripts do
0-iam_betty: Switch user to betty.\
1-who_am_i: Check current user.\
2-groups: Check current group of current user.\
3-new_owner: Change owner of a file.\
4-empty: Create an empty "hello" file.\
5-execute: Add execute perm for user to a file.\
6-multiple_permissions: Add multi perms to multi targets for 1 file.\
7-everybody: Add exe perm to everyone.
8-James_Bond: No perm for u and g but all perm for o.\
9-John_Doe: Specific change perm.\
10-mirror_permissions: Copy perms.\
11-directories_permissions: Give exe perm to all subdir of current dir, file untouched.
